# Тесты

Три уровня проверок, все запускаются из корня проекта.

## 1. Статическая валидация (без зависимостей)
```
python tests/check_static.py
```
Проверяет: манифест и иконки, перекрёстные ссылки id/классы/ассеты между
`index.html`, `app.js`, `style.css`, `sw.js`, баланс скобок.

## 2. Юнит-тесты логики (Node, без браузера)
```
node tests/unit.test.js
```
`tests/harness.js` поднимает мини-DOM и управляемые виртуальные часы
(rAF с каденцией 16 мс, setTimeout/setInterval по меткам времени) и
выполняет `app.js` в изолированном vm-контексте. Проверяется вся логика:
временная шкала сессии, паузы, стоп во время отсчёта, дрейф в фоне,
пикер, клавиатура, санитизация настроек, утечки таймеров.

## 3. Браузерные e2e-тесты (Python + Playwright)
```
python tests/browser_test.py
```
Настоящий Chromium: загрузка, service worker и офлайн, пикер, переключатели,
полный прогон сессии, пауза по тапу и по пробелу, поворот экрана, стресс
из 30 циклов старт/стоп, accessibility, манифест, отсутствие ошибок консоли.

## Скриншоты всех экранов
```
python tests/screenshots.py
```
Снимки сохраняются в корень как `shot_*.png` (в `.gitignore`).
